ОСТБАЛТИЙСКАЯ РЕСПУБЛИКА — ВЕРСИЯ 9

Состав:
- index.html — обновлённый портал на основе загруженной версии 8.

Что исправлено:
1. Возвращена выразительная шапка с названием «Остбалтийская Республика».
2. Сохранена верхняя навигация по разделам.
3. Панорамный баннер использует историческое фото Tallinna lauluväljak 1991.
4. Главный текстовый блок использует отдельное фото Snelli Park 1991.
5. Кнопок «Назад» и «Вперёд» нет.
6. «Инструменты сайта» скрыты по умолчанию и показываются только после входа с серверной ролью moderator, administrator или creator.
7. Проверка роли читает Supabase user.app_metadata.portal_role. Поле RP-фракции при регистрации не даёт прав доступа.
8. Добавлена вкладка визуального редактирования всех страниц.
9. Для модератора доступны новости и текстовая модерация; администратору — редактор, страницы, новости, фото и резервные копии; создателю — все разделы, включая описание ролей.

ВАЖНО ПРО РОЛИ И БЕЗОПАСНОСТЬ:
- В HTML оставь только Supabase Project URL и anon/public key.
- Никогда не вставляй service_role key в HTML.
- Роль доступа назначается доверенным серверным способом в Supabase app_metadata.portal_role:
  participant / moderator / administrator / creator.
- Нельзя давать пользователю возможность выбрать себе portal_role в форме регистрации.
- Одного скрытия кнопок недостаточно для защиты данных: перед публикацией общей CMS нужно настроить серверные проверки и RLS-политики Supabase.
- В текущей статической сборке тексты и новости редактора сохраняются в localStorage этого браузера. Они не синхронизируются между посетителями и устройствами, пока не подключено серверное хранилище.
